STUDENT INFORMATION + BIRTH DATE STRING
C# Windows Forms project.

How to open:
1. Extract the ZIP.
2. Open StudentInformation_CSharp.csproj in Visual Studio 2022.
3. Make sure the .NET 8 Desktop Development workload is installed.
4. Press F5.

The first form matches the Student Information figure.
Click "Birth Date String" to open the second form.
